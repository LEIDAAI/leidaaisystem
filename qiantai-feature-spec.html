01 · 阅读口径与测试准备

前台为独立 Vue3 + Vite 工程，无 vue-router；页面通过左侧导航与顶部导航切换，页面选择持久化到 localStorage，无 URL 深链、无 404 页。本文全部结论以当前源码实现为准，不构成对线上完成情况的额外背书。

事项明确口径测试使用方式
页面构成页面键位 chat / experts / skills / pricing / account / orders / consume；登录为全屏视图层；钱包、反馈等为弹窗。按导航逐页验收；刷新后停留在上次的页面（未登录时 account/orders/consume 回退对话页）。
数据状态标注【真实】后端接口；【演示】硬编码/本地 mock；【模拟】交互不上送服务端；【未对接/待开发】不作为已完成链路。演示数据数值与真实业务不一致不报缺陷；不把模拟交互当作真实链路验收证据。
会话与消息会话列表、历史消息、1688 商品表、obsUrl 报告、会员套餐信息走真实接口；流式回复为 SSE。【真实】以真实响应内容验收；注意报告预览依赖 /api/proxy 同源代理链路。
演示与模拟数据登录/注册/微信扫码、套餐与充值、订单与消耗记录、专家技能 MCP 目录、案例报告为本地 mock 或硬编码。【演示】【模拟】预置账号 17688894656 / 123456abc，万能验证码 123456；仅供演示测试。
本地存储dld_auth_v1 登录态、dld_last_page 页面记忆、dld-expert-workspace-v1 目录工作区、dld_promo_banner_closed、dld_left_collapsed/dld_left_width/dld_right_width 等。清缓存即恢复初始种子数据；先记录前置数据再操作，避免原型操作污染测试结论。
访问与保密前台公开地址 leidaai.github.io/leidaaiqiantai；不发布内网地址与真实密钥。页面原型链接不代表生产入口；输入真实手机号不会触发真实短信。

每项原型说明由“功能名称 + 逻辑说明”组成，逻辑说明固定给出：入口与角色、字段、操作步骤、状态规则、异常边界、关联页面、验收依据。文中测试项为待执行验收清单，不是已通过测试报告。

前台以“AI 选品对话工作台”为中心，围绕账户与商业化提供套餐/订单/消耗页面，并以专家、技能、MCP 目录组织能力入口。真实接口与本地演示数据混合，下表给出每模块的数据状态与验收要点。

模块功能与数据状态规则 / 可执行测试要点责任划分

F01 · 登录与游客

登录层为全屏三视图（验证码 / 密码 / 微信扫码），全部为 localStorage mock，不触发真实短信与真实微信认证。登录态持久化 dld_auth_v1，注册表 dld_reg_v1、密码表 dld_passwords_v1、微信绑定 dld_wx_bind_v1。

原型说明 · PN-F01-01 验证码登录与注册

功能名称验证码登录与注册（默认 tab）
逻辑说明

入口与角色：游客访问前台默认落地登录层；被拦截操作（购买、查看账户等）带原因文案打开登录层并默认聚焦验证码 tab。

字段：手机号（校验 ^1\d{10}$）、“获取验证码”按钮（60s 倒计时文案「60s后可重发」）、验证码输入、密码输入（仅未注册新号时追加，≥6 位）、主按钮「登录」/「注册并登录」。

  1. 输入合法手机号 → 点「获取验证码」→ 演示 toast 明示万能验证码 123456，按钮进入 60s 倒计时。
  2. 提交：命中预置/已注册号码 → 验证码正确即登录成功并关闭登录层。
  3. 未注册新号 → 提示「首次使用该手机号，请输入验证码并设置密码」并追加密码框，按钮文案变「注册并登录」；提交成功后注册手机号写 dld_reg_v1、密码写 dld_passwords_v1。
  4. 注册成功后延迟约 400ms 弹出欢迎赠积分弹窗（见 F09-02）。

状态规则：手机号非法时按钮允许点击但提示「请输入正确的手机号」；倒计时期间不可重发；登录态恢复在模块加载时完成，避免刷新出现登录墙闪烁。

异常边界：验证码错误提示「验证码错误（模拟验证码 123456）」；未注册号走密码 tab 提示「该手机号未注册，请使用验证码注册」；都不发送真实短信。

关联页面：登录成功回到原操作上下文；游客入口、密码登录、微信扫码（同视图切换）。

验收依据：步骤 1–3 逐条执行并截图 toast 与状态文案；断言 dld_reg_v1/dld_auth_v1 写入。

原型说明 · PN-F01-02 密码登录

功能名称密码登录（tab 二）
逻辑说明

入口与角色：登录层内切换“密码登录”tab；预置账号提示条展示 17688894656 / 123456abc。

字段：手机号、密码（支持明文/密文切换眼睛钮）、「登录」按钮。

  1. 输入预置账号或已注册密码表中的手机号 + 对应密码 → 登录成功。
  2. 「忘记密码」点击 → toast「演示环境暂不支持找回密码，请使用验证码登录」。

状态规则：密码显隐切换不改变已输入值；提交后命中即写登录态。

异常边界：未注册号提示「该手机号未注册，请使用验证码注册」；密码错误提示「密码错误」。

关联页面：验证码注册流程产生的密码可在此登录（两 tab 数据互通）。

验收依据：分别用预置账号、新注册号、错误密码三组用例回放，记录 toast 文案。

原型说明 · PN-F01-03 微信扫码与绑定

功能名称微信扫码登录与手机号绑定
逻辑说明

入口与角色：登录层默认落地视图为扫码；面向选择微信习惯的游客。

字段：二维码占位图、状态文案；绑定视图：手机号、验证码、「完成绑定并登录」按钮、「返回重新扫码」链接。

  1. 进入扫码视图 → 约 3.2s 模拟“已扫码” → 再 2.2s 出结果。
  2. 已绑定（dld_wx_bind_v1 命中）→ 直接登录成功。
  3. 未绑定 → 切换绑定视图，输入手机号 + 验证码（万能 123456）→「完成绑定并登录」，提交期间按钮呈「绑定中…」；成功写入绑定表并登录。

状态规则：演示条提供「重置扫码绑定」按钮，可清空 dld_wx_bind_v1 重走流程。

异常边界：二维码不代表真实微信认证成功；整个过程不与微信服务端交互。

关联页面：绑定成功即进入对话工作台。

验收依据：按步骤 1–3 走完整链路并重置一次验证可重复性。

原型说明 · PN-F01-04 游客访问与登录拦截

功能名称游客免登录访问与带原因拦截
逻辑说明

入口与角色：登录层「暂不登录，先看看→」进入游客态；未登录 点击受保护资源时统一走 requireLogin(reason)。

字段：拦截原因文案随触发点变化：购买积分包 / 购买套餐或积分包 / 查看账户信息 / 升级套餐 / 完成支付等。

  1. 游客可浏览工作台、专家/技能目录、套餐页（pricing 不拦截）。
  2. 点击 account / orders / consume 页或钱包、购买按钮 → 打开登录层并展示对应原因文案。
  3. 登录成功后回到触发前的操作上下文继续原动作（如重新打开钱包）。

状态规则：游客态不持久化登录数据；登录态被清（退出）时若停留在受保护页自动回退对话页。

异常边界：未登录输入框仍可输入，发送前才拦截与否以当前实现为准（以发送按钮反馈为准验收）。

验收依据（关联页面）：逐个触发点核对原因文案与登录成功后的回续行为。

异常验收：登录层三种视图切换不丢失已填内容。

资料：LoginView.vue、components/Modals.vue（登录视图）、stores/auth.ts

F02 · AI 选品对话工作台

前台核心页面，三栏布局：左栏会话列表（Sidebar）、中栏对话区（ChatPane + Composer）、右栏预览面板（RightPanel）。会话与消息走真实接口，回复为 SSE 流式；专家/技能目录与案例为演示数据。

原型说明 · PN-F02-01 工作台首屏与引导

功能名称新会话首屏 hero 引导
逻辑说明

入口与角色：「开启新对话」或登录后默认进入；面向开始一次选品咨询的用户。

字段：标题「跨境电商运营助手」；专家/技能双 tab；平台筛选（1688 / OZON / 亚马逊 / TEMU）；场景 chips；推荐卡片每页 6 个 + 翻页；浮动按钮（用户反馈、消息交互演示）。

  1. 选择平台与场景 → 卡片列表联动筛选。
  2. 专家卡「看案例」打开案例弹窗（见 PN-F07-03）。
  3. 专家卡「立即使用」→ 将该专家 prompts[0] 填入输入框并自动发送。
  4. 技能卡「前往使用」→ 填入提示词跳对话区，不自动发送（与专家差异点）。

状态规则：卡片数据全部硬编码【演示】；已发出首条消息后 hero 收起进入流式布局。

异常边界：无网络不阻塞首屏展示（卡片为本地数据）。

关联页面：pn-F07（目录）、pn-F09-01（反馈弹窗）。

验收依据：截图 hero 布局与双 tab 筛选联动；分别点专家/技能卡验证自动发送差异。

原型说明 · PN-F02-02 选品发送与 SSE 流式回复

功能名称消息发送、SSE 流式渲染与停止生成
逻辑说明

入口与角色：对话区 Composer；所有登录/游客用户。

字段：textarea 占位「输入您的选品需求...（Enter 发送，Shift+Enter 换行）」自适应高度；发送按钮双态「开始查询」/「停止生成」；运行中消息状态文案「· 正在执行」。

  1. 输入需求 Enter 或点「开始查询」→ 建立会话/追加轮次，消息进入流式渲染（liveText 逐段刷新）。
  2. 运行中再次 Enter → toast「当前对话正在生成，请等待完成或先停止生成」。
  3. 点「停止生成」→ 中断 SSE，消息定格已生成内容并给出状态标记。
  4. 回复完成 → 附推荐追问 chips（见 PN-F02-07）；1688 类问题附商品卡/明细（PN-F02-04），报告任务附 obsUrl 卡片（PN-F02-05）。

状态规则：消息流底部显示「消息加载中…」直到历史拉取完成；内容区距底 >120px 时出现「跳到最新」浮钮；页脚固定免责声明「内容由AI大模型生成，请仔细甄别」；切换会话会重置右栏预览上下文。

异常边界：SSE 中断/异常在消息内呈现 errorText，不弹阻塞对话框；刷新页面后运行中任务以接口实际状态恢复。

关联页面：pn-F02-09（会话状态同步）、pn-F05/F06（产生消耗的口径说明见 F06-02）。

验收依据：录制一次完整流式回复与一次停止操作；断言停止后 no further chunk 渲染。

原型说明 · PN-F02-03 专家 / 技能身份携带发送

功能名称输入区专家 / 技能浮窗选择
逻辑说明

入口与角色：Composer 工具条打开浮窗；将专家/技能作为“身份”随消息发送。

字段：浮窗内搜索框 + 平台筛选 + 场景 chips；推荐列表 ≤6 个；已选项在工具条以 chip 呈现（可移除）；身份切换下拉（当前 v-if=false 隐藏，不做验收）。

  1. 打开浮窗 → 搜索/筛选 → 点选专家或技能 → toast「已选择专家…随消息一起发送」。
  2. 再次点击同一项可反选取消。
  3. 发送消息时所选身份随请求携带，影响回复口径。

状态规则：专家与技能单选槽位各自独立；跨消息保留至手动移除。

入口与角色：全局；统管删除确认、升级确认（两步）、支付弹窗（F03-02）等弹窗的开合与层级。

字段：遮罩层、弹窗容器、右上角关闭按钮、主 / 次按钮；危险操作（删除会话）红色主按钮。

步骤：

  1. 点击遮罩或右上角关闭按钮可关闭常规弹窗。
  2. 按 Esc 关闭最顶层弹窗；支付弹窗在倒计时进行中需二次确认（防误关）。
  3. 删除确认弹窗点击「删除」后本地移除会话并 toast 提示。

状态规则：弹窗互斥，同一时刻仅展示一个；支付倒计时不受弹窗关闭影响（订单保留待支付状态）。

异常边界：连续快速开关不产生叠层；Esc 在输入框聚焦时优先冒泡处理弹窗。

关联页面：F02-09（删除会话）、F03-02（支付弹窗）、F03-03（升级确认）。

验收依据：Esc / 遮罩 / 关闭按钮三种方式均可关闭；删除需确认后生效。

资料：components/Modals.vue（反馈 ≤4 截图 + 50 积分、欢迎弹窗、删除确认、升级两步）、localStorage 键 dld_welcome_gift_v1。
